## 0. 先知道这篇论文在做什么

论文研究的是：**让一个强化学习智能体学会管理投资组合，而且能适应不同投资者临时指定的股票池。**

用小白视角理解：

- 环境：金融市场，每天给你股票价格和指标。
- 智能体：模型，相当于一个自动基金经理。
- 状态：最近几天所有股票的价格、技术指标、日期信息。
- 动作：今天把钱分到现金和每只股票上的比例。
- 奖励：投资组合表现好不好。
- 策略：模型学出来的“看到市场状态后如何分配资金”的规则。

## 2. MDP：马尔可夫决策过程

参考资料：

- 第 2 章：马尔可夫决策过程
- 重点看 2.1 什么是 MDP、2.2 状态/奖励/策略、2.3 MDP 的目标

你需要掌握：

- MDP 五元组：状态集合、动作集合、状态转移、奖励函数、折扣因子。
- 马尔可夫性：下一步主要由当前状态和动作决定。
- 回合制任务和连续任务的区别。

对应论文：

- 论文把 PM 表示成 `(S, A, P, R, gamma)`。
- 普通 PM 是 GSP 上的 MDP；本文扩展到 CSP，并用 mask token 保持状态维度一致。

小例子：

假设只有 3 只股票和现金：

- 状态：过去 10 天的 3 只股票数据。
- 动作：`[现金 0.2, 股票A 0.5, 股票B 0.3, 股票C 0.0]`。
- 奖励：明天组合价值涨了多少，或代码里用的 Sharpe Ratio。

学习目标：

- 能画出“状态 -> 动作 -> 奖励 -> 下一状态”的循环。
- 能解释为什么投资组合管理适合建模成序列决策问题。

## 3. 收益、价值函数与贝尔曼方程

参考资料：

- 第 3 章：贝尔曼方程
- 重点看 3.3 行动价值函数与贝尔曼方程、3.4 贝尔曼最优方程

你需要掌握：

- 回报 Return：从当前开始，未来奖励的折扣总和。
- 状态价值函数 `V(s)`：处在状态 s 有多好。
- 动作价值函数 `Q(s, a)`：在状态 s 做动作 a 有多好。
- 贝尔曼思想：当前价值 = 当前奖励 + 未来价值。

对应论文：

- SAC 的 Critic 学的是 Q 值。
- 第 4.2 节的 Q 网络优化本质上是在最小化 Bellman residual。

对应代码：

- `AgentMaskSAC.get_obj_critic_raw`
- `CriticMaskSAC.get_q_min`
- `CriticMaskSAC.get_q1_q2`

小白理解：

如果今天把 50% 钱买 A 股票，不只看明天赚多少，还要看这个动作会把你带到什么后续局面。Q 值就是“这一步动作加上未来可能收益”的综合评分。

学习目标：

- 能解释为什么 Critic 要估计 `Q(s, a)`。
- 能看懂代码中 `q_labels = rewards + gamma * (...)` 是贝尔曼目标。

## 4. Q 学习、DQN 与经验回放

参考资料：

- 第 6 章：TD 方法
- 第 6.4 节：Q 学习
- 第 8 章：DQN
- 重点看 8.2.1 经验回放、8.2.3 目标网络

你需要掌握：

- TD 学习：不等一整局结束，边走边更新价值估计。
- Q 学习：用下一状态的最大 Q 值更新当前 Q 值。
- 经验回放 Replay Buffer：把交互样本存起来，随机抽 batch 训练。
- 目标网络 Target Network：用一个慢更新的网络提供稳定目标。

对应论文：

- EarnMore 使用 SAC，不是 DQN，但也使用 replay buffer 和 target Q network。
- 这些思想与 DQN 一脉相承。

对应代码：

- `csp/EarnMore-main/pm/utils/replay_buffer.py`
- `AgentMaskSAC.soft_update`
- `AgentMaskSAC.update_net`

学习目标：

- 能解释为什么不能只用最新一天的数据训练。
- 能解释 target network 为什么让训练更稳定。

学习目标：

## 7. SAC：Soft Actor-Critic

参考资料：

- 参考资料中没有单独完整讲 SAC，但可先学第 9 章 Actor-Critic 和第 10 章 DDPG/PPO，再回到论文第 4.2 节。

你需要掌握：

- SAC 是离策略 Actor-Critic。
- 它有两个 Q 网络，取较小值，减少过估计。
- 它有熵正则，鼓励策略保持探索。
- alpha 控制“探索”和“利用”的平衡。

对应论文：

- Q 网络优化：学习 soft Q value。
- 策略网络优化：最大化 Q 值，同时保留熵。
- alpha 优化：自动调整熵权重。

对应代码：

- `AgentMaskSAC.get_obj_critic_raw`
- `AgentMaskSAC.update_net`
- `ActorMaskSAC.get_action_logprob`
- `CriticMaskSAC.get_q_min`

学习目标：

- 能看懂 `next_qs - next_logprobs * alpha` 的意思：未来价值要加上探索价值。
- 能理解为什么有 `q1` 和 `q2` 两个 Q 值。

## 9. Maskable Stock Representation

参考资料：

- 第 7 章：神经网络和 Q 学习
- 第 8 章：DQN 中的神经网络思想
- 论文第 4.1 节

你需要掌握：

- 表示学习：把原始特征变成更有用的向量。
- mask token：用一个可学习向量代表“被遮住/不想交易”的股票。
- 自监督学习：不用人工标签，通过“遮住再重建”学习表示。

对应论文：

- 股票级表示：每只股票先单独编码。
- 池级表示：通过 mask 和重建学习股票之间关系。
- 可掩码表示：把 masked token 填回，使 Actor/Critic 看到固定长度状态。

对应代码：

- `TimesEmbed`
- `MaskTimeState.forward_encoder`
- `MaskTimeState.forward_state`
- `MaskTimeState.forward_loss`

小白理解：

模型像做完形填空：遮住一部分股票，让模型根据其他股票猜被遮股票的价格/特征。能猜好，说明模型学到了股票之间的联系。

学习目标：

- 能解释为什么不能简单删除 CSP 外股票。
- 能说明 mask token 如何让不同 CSP 仍保持同一输入维度。

## 10. 重加权与稀疏投资组合

参考资料：

- 可先回顾 softmax：把一组分数变成概率/权重。
- 论文第 4.3 节。

你需要掌握：

- softmax：分数越高，权重越大。
- 温度参数 T：控制分布尖锐程度。
- T 小：更集中、更稀疏。
- T 大：更平均。

对应代码：

- `pm/utils/helpers.py`
- `get_action_wrapper`
- `forward_action_wrapper`
- `get_action_logprob_wrapper`

小例子：

如果三只股票得分是 `[1, 2, 5]`：

- 普通 softmax 会给第三只股票最高权重；
- T 很小时，第三只股票几乎拿走全部权重；
- T 很大时，三只股票权重差距变小。

学习目标：

- 能解释重加权为什么能减少对低收益股票的“微小无效投资”。
- 能理解为什么稀疏化可能提升收益，但也可能增加风险。

## 11. 金融评估指标

参考论文附录 A。

你需要掌握：

- ARR：年化收益率，越高越好。
- SR：夏普比率，收益/波动，越高越好。
- VOL：波动率，越低通常越稳。
- MDD：最大回撤，越低通常越安全。
- CR：收益相对最大回撤。
- SoR：只考虑下行波动的风险调整收益。

对应代码：

- `pm/metrics/metric_new.py`
- `AgentMaskSAC.validate_net`

学习目标：

- 不只看收益，也要看风险。
- 能解释为什么 EarnMore 收益强，但部分风险指标不一定最好。

## 一句话总图

```text
市场数据
  -> Dataset 读取股票和 CSP mask
  -> Environment 生成状态和奖励
  -> MaskTimeState 学习可掩码股票表示
  -> Actor 输出组合权重
  -> Re-weighting 让权重更稀疏、更尊重 mask
  -> Critic 评估动作好坏
  -> ReplayBuffer + SAC 反复更新模型
```
