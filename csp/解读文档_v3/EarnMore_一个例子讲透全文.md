# EarnMore：用一个例子讲透全文

> 论文：**Reinforcement Learning with Maskable Stock Representation for Portfolio Management in Customizable Stock Pools**（WWW'24，南洋理工 / 浙大 / Skywork AI）
>
> 一句话总结：**只训练一次模型，就能服务"每个人各选各的股票"这种千人千面的需求**——靠的是把"不想要的股票"用一个可学习的"掩码占位符"盖住。
>
> 阅读方式：全文围绕**老王**这个虚构散户展开。看懂老王的故事，就看懂了论文。

---

## 0. 先认识三个主角和一个名词

| 名词 | 大白话 | 例子里指什么 |
|---|---|---|
| 投资组合管理（PM） | 手里有 100 万，分别买多少哪几只股票、留多少现金 | 老王给 100 万排个"分配方案" |
| 股票池（Stock Pool） | 你允许买的股票范围 | 老王只在这几只里挑 |
| 全局股票池（GSP） | 市场里**所有**能买的股票（全集） | 假设市场就 4 只股：苹果、微软、摩根、可口可乐 |
| 可定制股票池（CSP） | 投资者**自己挑出来的子集** | 老王只想买科技股 → {苹果, 微软} |

## 1. 论文要解决的真问题（Why）

老王是散户，他只信科技股，想买 **{苹果, 微软}**。
他朋友老李是保守派，只买 **{摩根, 可口可乐}**。
过两周老王听说苹果要出事，想临时把苹果踢出去……

**传统强化学习（RL）选股模型的死穴**：模型是"按固定股票池"训练的。
- 老王要 2 只 → 得为这个组合**单独训一个模型**。
- 老李要另外 2 只 → 再训一个。
- 老王中途改主意 → **再训一次**。

> 从 30 只股里随便挑 5 只就有 **14 万种**组合。给每种组合都训一个模型？**根本不可能。**

所以论文提出：**能不能只训练一个"通用大脑"，谁来都能用，还能随时增删股票？**
这个"通用大脑"就叫 **EarnMore**。

---

## 2. 核心妙招：把"不想要的股票"盖起来（Maskable，可掩码）

### 2.1 朴素想法为什么不行

最直接的念头是：老王只要 2 只，那就**只把这 2 只喂给模型**。
但这样有 3 个致命问题：

1. **维度对不齐**：老王给 2 只、老李给 2 只、别人给 5 只，模型的输入/输出尺寸老在变，没法复用。
2. **同样数量却分不清**：老王和老李都给 2 只，但内容完全不同，模型会"懵"。
3. **丢掉了股票间的关系**：苹果和微软是竞争关系、和英特尔是合作关系……直接扔掉其它股票，这些隐藏关联就丢了，决策变差。

### 2.2 论文的答案：盖住，而不是扔掉

借鉴 NLP 里 BERT 的完形填空思想：**不删除，而是用一个统一的"占位符"盖住不想要的股票。**

这个占位符叫 **掩码 token（masked token，记作 [M]）**，是一个**可学习**的向量。

```
全局池(GSP)固定 4 个位置：  [ 苹果 ] [ 微软 ] [ 摩根 ] [ 可乐 ]

老王只要科技股，于是：       [ 苹果 ] [ 微软 ] [ [M] ] [ [M] ]
                                              ↑盖住   ↑盖住

老李只要金融消费，于是：     [ [M] ] [ [M] ] [ 摩根 ] [ 可乐 ]
```

**好处一次解决全部 3 个问题**：
- 输入永远是 4 个位置 → 维度永远对齐 ✅
- [M] 出现在不同位置 → 模型一眼看出老王和老李要的不一样 ✅
- 4 只股票全在场上 → 关系不丢，模型还能"参考"被盖住股票的存在 ✅

而且模型**能感知到 [M]**，会主动避免把钱分给被盖住的股票——这正是"听投资者的话"。

## 3. 怎么让模型"看懂"股票？两层表征（How·上）

光有占位符还不够，模型得先把每只股票变成有意义的数字向量（表征 / embedding）。EarnMore 分两层来做。

### 3.1 第一层：股票级表征（看每只股票自己的历史）

输入每只股票过去 10 天的数据：
- **OHLC 价格**（开盘/最高/最低/收盘）、**技术指标**（如均线、MACD 共 95 个）→ 连续数值，用**一维卷积**提取（"稠密"特征）；
- **时间信息**（星期几、第几个交易日）→ 离散类别，用**嵌入层查表**（"稀疏"特征）。

两者相加，得到苹果的一个向量、微软的一个向量……
> 📌 这一层只看"每只股票纵向的自己的时间序列"，**还没看股票之间的横向关系**。

### 3.2 第二层：池级表征（看股票之间的关系）—— 全文最关键

用**掩码自编码器（MAE）的"完形填空"**来学股票间的关系，过程像考试：

```
  4 只股票的股票级向量
        │
   ① 随机盖住一大半（论文盖 60%~80%，比如盖住 苹果、微软、摩根）
        │
   ② 只把"没盖住的"(可乐) 喂进【编码器 Encoder】→ 压缩出精华
        │
   ③ 用 [M] 把空位补回 4 个 →【解码器 Decoder】
        │
   ④ 让 Decoder 去"猜"被盖住那几只(苹果/微软/摩根)的价格
        │
   ⑤ 猜得越准越好（用 MSE 均方误差当损失，只算被盖住股票的误差）
```

**为什么这招能学到关系？**
要想仅凭"可口可乐"就猜对"苹果"的价格，模型**必须真正理解股票之间的联动规律**（哪些一起涨、哪些对着干）。这就像你能根据"今天下雨"猜出"地是湿的"——因为你懂因果。

> 训练时盖多少是**随机**的（截断高斯分布，集中在 60%~80%），这恰好在**模拟各种各样的 CSP**：盖得多 = 投资者只挑了几只；盖得少 = 投资者挑了一大堆。一次训练，覆盖所有定制场景。

学完后，"补好 [M] 的那一整套向量"就叫 **可掩码股票表征 ρ**，它就是后面强化学习要用的**状态（state）**。

> 📌 额外细节：保留一个特殊的 **[CLS] token** 专门代表"**现金**"这个特殊资产，让模型有专门通道决定"持币多少"。

## 4. 怎么做决策并赚钱？强化学习 SAC（How·中）

有了状态 ρ，就进入强化学习（RL）。把炒股建模成一个循环：

```
看市场(状态 ρ) → 出方案(动作 a：给每只股+现金分配比例) → 赚/赔(奖励 r) → 看新市场…
```

EarnMore 用的算法是 **SAC（Soft Actor-Critic）**，有两个角色：

- **Actor（演员 / 操盘手）**：根据状态输出"分配方案"，比如 `[现金10%, 苹果50%, 微软40%, [M]0%, [M]0%]`。它能看到 [M]，会自觉不给被盖股票分钱。
- **Critic（评论家 / 风控）**：给 Actor 的方案打分，告诉它"这个方案好不好"，指导它越做越好。

几个关键设定（不必深究公式，记住意思即可）：
- **奖励 r = 组合市值的变化**（赚了为正，赔了为负）。
- **熵正则（SAC 的特色）**：鼓励操盘手适当"探索"新方案，别太死板；用一个自动调节的温度 α 平衡"探索 vs 守成"。
- **重参数化技巧**：一个让"随机采样"也能正常反向传播训练的数学手段。
- **额外惩罚**：一旦 Actor 偷偷给被盖股票([M])分了钱，就用一个**监督损失**直接揍它一下，逼它清零。

> 📌 **端到端一起训**：第 3 节的"完形填空"和这里的"强化学习"是**同时训练**的，而不是先训好表征再冻住。论文实验证明：分开训会让"猜价格"和"做决策"两个目标脱节，效果更差。

## 5. 临门一脚：重加权，把"撒胡椒面"变成"重拳出击"（How·下）

操盘手 Actor 有个毛病：容易**撒胡椒面**——给一堆没前途的股票都分一点点钱，钱被稀释，赚不动。

论文加了一个 **重加权（Re-weighting）** 机制：在 softmax 里加一个**温度参数 T**：

$$ Re(x)_i = \frac{e^{x_i/T}}{\sum_j e^{x_j/T}} $$

直觉就一句话：**T 越小，分配越"尖锐"、越集中**。

| T 取值 | 效果 | 老王的组合会变成 |
|---|---|---|
| T → 0 | 极端集中 | 几乎全押最看好的那一只 |
| **T = 0.1（论文最优）** | 集中、果断 | 苹果60% 微软35% 现金5%，零碎仓位清零 |
| T = 1 | 普通 softmax | 平平淡淡 |
| T > 1 | 越来越平均 | 接近平均分配，等于没主见 |

效果：**把微小仓位直接清零（稀疏化）**，钱集中到最看好的少数股票上，收益大涨。
代价：组合更集中 → 风险（最大回撤）会略增。论文认为这笔买卖值。

## 6. 把整条流水线串起来（老王的一次完整决策）

```
① 老王说："我只要科技股。"
        ↓
② 全局池 [苹果,微软,摩根,可乐] → 盖住非科技：[苹果,微软,[M],[M]]
        ↓
③ 股票级表征：把每个位置的过去10天数据变成向量
        ↓
④ 池级表征(MAE)：编码-解码，得到懂"股票关系"的状态 ρ
        ↓
⑤ Actor 出方案 → 重加权(T=0.1)集中化 → [现金5%, 苹果60%, 微软35%, [M]0%, [M]0%]
        ↓
⑥ 按方案持仓一天 → 市值变化 = 奖励 → Critic 打分 → 微调大脑
        ↓
   第二天回到 ④，循环……
```

**老李来了怎么办？** 完全不用重训！只把第 ② 步的掩码换成 `[[M],[M],摩根,可乐]`，**同一个大脑**立刻就能给老李服务。这就是"一次训练，人人可用"。

**老王中途想踢掉苹果？** 也不用重训，下一步直接把苹果也盖成 [M] 即可，模型实时适配。

## 7. 实验：到底有多强（Experiments）

### 7.1 怎么做的实验

- **数据**：美股，雅虎财经日频数据，清洗后 3094 只股票、95 个技术指标（Qlib 的 Alpha158）。
- **两个市场**：SP500（取 420 只为 GSP）、DJ30（28 只为 GSP）。
- **状态尺寸**：`(批128, 股票数N, 历史10天, 特征102)`；注意**成交量因数值过大被剔除**。
- **8 个数据集**：每个市场 1 个 GSP + 3 个 CSP（CSP1 科技、CSP2 金融、CSP3 服务）。
- **对比对象**：14 个主流方法（规则/机器学习/深度学习/强化学习四大类），6 个金融指标。
- **严谨性**：每组跑 9 次（3 个时间段 × 3 个随机种子）取平均。

### 7.2 6 个评价指标（看懂这几个就够）

| 指标            | 含义                    | 方向     |
| ------------- | --------------------- | ------ |
| **ARR** 年化收益率 | 一年赚百分之几               | 越大越好 ↑ |
| **SR** 夏普比率   | 每承担 1 单位风险换来多少收益（性价比） | 越大越好 ↑ |
| **CR** 卡玛比率   | 收益 ÷ 最大回撤             | 越大越好 ↑ |
| **SoR** 索提诺比率 | 只惩罚"下跌波动"的夏普改良版       | 越大越好 ↑ |
| **MDD** 最大回撤  | 从最高点最多跌了多少（最坏情况）      | 越小越好 ↓ |
| **VOL** 波动率   | 收益颠簸程度                | 越小越好 ↓ |

### 7.3 主要结果

**① 全局池上碾压 14 个对手**（SP500）：

| 方法 | 年化收益 ARR | 夏普 SR |
|---|---|---|
| 市场基准 | 9.3% | 0.56 |
| DeepTrader（第二名） | 60.3% | 1.98 |
| **EarnMore** | **97.2%** | **2.03** |

> 收益比第二名再高出 **40%+**。DJ30 上 ARR 也提升 46.7%。

**② 定制池上优势更大**（这是论文的主场景）。例如科技股 CSP1：

| 方法 | SP500-ARR | DJ30-ARR |
|---|---|---|
| DeepTrader | 34.0% | 27.7% |
| **EarnMore** | **122.6%** | **54.0%** |

**③ 抗跌**：2020 年新冠暴跌（SP500 跌 31.8%）时，EarnMore 受冲击远小于对手，反弹后还能继续赚。

**④ 真实增删股票也稳**（论文图 4 的 4 个真实案例）：
- GE 退市 / 苹果暴跌时**移除**它们 → 收益小幅提升；
- 故意把正在下跌的微软**塞进**池子捣乱 → 模型自动减少微软仓位，几乎不受影响；
- 把利好的高盛**加入** → 收益明显增长。
> 说明它真的能听懂投资者的临时决策。

### 7.4 消融实验：每个零件都有用吗（RQ1）

| 版本 | 说明 | SP500 年化 |
|---|---|---|
| w/o-MR | 去掉"掩码表征 + 重加权"（最朴素） | 33.2% |
| w/o-M | 加回"重加权"，仍无掩码表征 | 74.8% |
| **完整 EarnMore** | 全都有 | **97.2%** |

结论：**重加权**和**可掩码表征**各自都带来明显提升，缺一不可。代价是组合更集中、回撤(MDD)略升。

### 7.5 为什么"笨办法"不行 & 效率（RQ2 / RQ3）

- **RQ2**：从零训练、微调、动作掩码这三种笨办法，都打不过 EarnMore，且前两种**没法在交易中实时改池子**。
- **RQ3**：笨办法每换一个 CSP 就要重训一次，时间成本线性暴涨；EarnMore **只训一次**，CSP 越多，效率优势越夸张。

## 9. 训练 vs 推理：两个阶段到底在干嘛

前面讲的是"零件"，这一节讲"开机流程"。EarnMore 的一生分两段：
**训练阶段**（把大脑练出来，关起门来自己刷题）和 **推理阶段**（大脑上岗，真给老王服务）。

### 9.0 一句话先抓住本质差异

> **训练时，"盖哪些股票"是模型自己随机决定的（刷遍所有可能的 CSP）；
> 推理时，"盖哪些股票"是老王说了算的（他不要哪只就盖哪只）。**

就这一处不同，决定了"一次训练、人人可用"。其它步骤（求表征、出方案）两阶段几乎一模一样。

---

### 9.1 训练阶段：关门刷题（对应论文算法 1）

训练的目标：把所有可学习的参数（卷积、嵌入、编码器、解码器、Actor、Critic、掩码 token [M]）都调到最优。
论文一共练 **2000 个回合（episode）**，每个回合就是"从某个历史起点把那段行情从头走到尾"。

训练像一台**两冲程发动机**，反复交替做两件事：

#### 冲程 A：攒经验（与环境交互，把数据塞进"回放缓冲区"）

模型化身操盘手，在历史行情里一天天往前走、做决策、记录结果。**关键在第 2 步的"随机盖"**：

```
第 t 天（训练时）：
 ① 取全局池 4 只股 [苹果,微软,摩根,可乐] 过去10天数据
 ② 【随机】采一个掩码率 r（论文≈60%~80%）→ 这次随机盖住比如 [微软,摩根,可乐]
        ↑↑↑ 这一步在"假装"出一个临时 CSP：本回合只剩苹果
 ③ 求股票级表征 → MAE 编码解码 → 得到状态 ρ
 ④ Actor 出方案 → 重加权 → 比如 [现金20%, 苹果80%, [M]0%,[M]0%,[M]0%]
 ⑤ 行情走到第 t+1 天，算出市值变化 → 这就是奖励 r
 ⑥ 把这条经历 (状态, 动作, 奖励, 下一状态) 存进【回放缓冲区 D】
```

> 📌 **为什么要"随机盖"？** 这是全文最聪明的一招。第 1 天可能只剩苹果，第 2 天随机盖成只剩微软+可乐，第 3 天又换……
> 练 2000 回合下来，模型相当于**把"投资者可能挑出的各种股票组合（CSP）"全都演练过无数遍**。
> 所以它学到的不是"怎么管这 4 只固定股"，而是"**给我任意一个子集，我都会管**"的通用能力。

> 📌 **回放缓冲区（replay buffer）是什么？** 一个能装 10 万条经历的"错题本"。攒着是为了下一步反复抽出来学，比"用一次就扔"高效得多（这是 SAC 这类 off-policy 算法的标配）。

#### 冲程 B：做题（从缓冲区抽经验，更新参数）

从错题本里随机抽一批（128 条），按**固定顺序**更新参数（论文强调必须分步、不能合在一起，否则训练不稳）：

```
① 更新 Critic（Q 网络）：让"打分"更准
② 更新 Actor（策略网络）：让"出的方案"得分更高
③ 调节温度 α：自动平衡"探索 vs 守成"
④ 软更新目标网络：给打分提供一个稳定的参照系
⑤ 更新可掩码表征（卷积/编码器/解码器/[M]）：让"猜被盖股票价格"更准
```

> 📌 第⑤步就是第 3 节那个"完形填空"在训练里的落点——它和 RL 的①~④**同步进行（端到端）**，而不是先练好再冻住。

#### 为什么必须"分步"，不能"合在一起"？

论文特别强调：上面这 5 步**必须排队分别更新**，**绝不能**把"猜价损失"和"赚钱损失"加权求和成一个总损失、一次性反向传播更新所有参数。否则训练会发散。理由有三：

- **① 表征是"地基"，RL 是"楼"，边盖楼边挖地基 → 楼裂。**
  Critic 学的是 `Q(ρ, 动作)`，**以状态 ρ 为输入**。若在更新 Critic 的同一步里把表征网络也改了，ρ 本身就变了——地基一直在动，Critic 永远学不到稳定映射。RL 本就有"移动目标"问题（所以才用目标网络稳住），再让输入状态一起晃，就是两头同时晃。

  > **🧩 小贴士：什么是"移动目标"问题和"目标网络"？**
  >
  > Q 网络要学"这步从现在到未来共能赚多少"，但未来还没发生、没有标准答案，于是用一个**自我递推**公式当目标：
  > `Q(今天,动作) ≈ 今天奖励 r + γ·Q(明天,动作)`。注意右边的"标准答案"里**也有一个 Q，且是同一个网络算的**——等于**学生自己出题、自己当标准答案**。
  >
  > 麻烦来了：你调参数让"预测"去够"目标"，可目标也是这个网络算的，**你一动它也跟着动**。像**追自己的尾巴**——永远咬不到，原地震荡甚至发散。这就是"移动目标（moving target）"问题。
  >
  > 解法 = **目标网络**：复制一份 Q、专门用来算右边的"标准答案"，但让它**更新得极慢**，短期内基本不动，给主网络一个**暂时固定的靶子**去瞄。EarnMore 里就是公式 (5b) 的 `Q_{θ̄}`，配合软更新 `θ̄ ← τθ + (1−τ)θ̄`（τ 很小，目标网络每次只朝主网络挪一点点）。
  >
  > 所以这条原因①可以这样理解：RL **已经**费劲把"靶子"稳住了（目标网络），你要是再把"靶子下面的地面（输入状态 ρ）"也一起晃，**不动的靶子立在晃动的地面上照样瞄不准**——两个移动叠加，训练必崩。

- **② 两个目标在打架，合成一个梯度会互相拉扯。**
  "猜价损失"想把 ρ 调成利于还原价格的样子，"赚钱损失"想把 ρ 调成利于选涨股的样子——这俩不是一回事（论文：会在"自监督价格预测"与"RL 决策"之间产生割裂）。加权求和后对**共享的表征网络**做一次反传，两股梯度在同一步朝不同方向硬拽它，参数来回震荡。
  > 类比：一个学生，A 教练喊"练投篮"、B 教练喊"练防守"，把两句**平均成一句同时吼**→ 学生懵；让两个教练**轮流各带一会儿**→ 都学得好。分步就是"轮流带"。

- **③ off-policy 缓冲区里的旧数据分布被搅乱。**
  错题本里存的是用**旧表征**算出的经历。若表征被赚钱梯度猛改，新表征和缓冲区里旧经历就对不上口径——抽出来学的数据分布被搅乱（论文原话："对 RL 过程所采样数据的分布产生负面影响"），学习信号变脏。

**分步为什么稳**：解耦。先在**当前固定的表征**上把 Q/α/Actor 更新好（RL 在稳定地基上学），最后才**单独**用重建损失轻轻更新一次表征（地基只在这一步动、幅度可控）。每一步只动一个变量，互不打架。

> 📌 老王类比：表征 ρ = 老王的"世界观"，Actor/Critic = 他的"操作手感"。
> **合在一起** = 一边重塑世界观、一边练手感、还同一秒做 → 精神分裂、忽赚忽亏；
> **分步** = 先在当下世界观里把手感练扎实，再慢慢微调世界观一点点 → 越练越稳。

冲程 A、B 不断交替，2000 回合后，整个大脑（含那个关键的 [M] 向量）就练成了。**训练产物 = 一套定型的参数。**

### 9.2 推理阶段：上岗服务（对应论文算法 2）

训练完，参数**全部冻结**，不再学习。现在老王真的来了。
推理和训练流程几乎一样，**只有第②步的"盖谁"换了主人**：

```
老王说："我只要科技股 {苹果, 微软}。"

第 t 天（推理时）：
 ① 取全局池 4 只股过去10天数据
 ② 【按老王的 CSP】盖住不在池里的 → [苹果, 微软, [M], [M]]
        ↑↑↑ 不再随机！摩根、可乐不在老王名单 → 盖掉
 ③ 求股票级表征 → MAE 编码解码 → 状态 ρ
 ④ Actor 出方案 → 重加权 → [现金5%, 苹果60%, 微软35%, [M]0%, [M]0%]
 ⑤ 这就是今天给老王的持仓建议 W_t（不算奖励、不更新参数）
 ⑥ 明天回到①，继续给出建议……
```

对比一眼看懂：

| | 训练阶段（算法1） | 推理阶段（算法2） |
|---|---|---|
| 掩码谁来定 | **模型随机采样**（模拟所有 CSP） | **投资者指定**（他的 CSP 说了算） |
| 要不要算奖励 | 要（指导学习） | 不要 |
| 要不要更新参数 | 要（反复刷题） | **不要**（参数已冻结） |
| 有没有回放缓冲区 | 有 | 没有（来一天算一天） |
| 目的 | 练出通用大脑 | 给具体投资者出方案 |

---

### 9.3 这套设计最妙的地方：老李 / 改主意，零成本

因为通用大脑在训练时已经"见过几乎所有 CSP"，上岗后换人、换池都**只是换第②步盖谁，不需要任何重新训练**：

- **老李来了**（要金融消费）：第②步改成 `[[M], [M], 摩根, 可乐]`，同一套冻结参数立刻出方案。
- **老王第 t 天想踢掉苹果**：从第 t 天起第②步改成 `[[M], 微软, [M], [M]]`，模型实时适配，无缝衔接。

这正是论文第 7 节实验里"GE 退市就移除、把高盛加入、把下跌的微软塞进去捣乱"那些案例的底层机制——**全部发生在推理阶段，靠的就是临时改一下掩码。**

> 📌 一句话收尾：**训练 = 用"随机盖"把所有可能的股票组合都练一遍，练出一个通用大脑；推理 = 用"投资者指定的盖法"，让这个大脑当场给任何人、任何股票池出方案。**
