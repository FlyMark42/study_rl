# 参考资料索引（_index）

本目录为「参考资料」里的书籍生成**纯文本索引**，方便用 `grep` 快速检索、定位页码。

## 收录书籍

| 书籍 | 来源 | 全文检索文件 | 目录文件 |
|------|------|------|------|
| 《深度学习入门4：强化学习》（斋藤康毅） | 有文字层 PDF，pdfplumber 直接提取 | `全文.txt` | `目录.md` |
| 《深度强化学习》（王树森） | **扫描版**，先 OCR 成 md 再提取 | `全文_王树森.txt` | `目录_王树森.md` |

## 页标记约定

两本书的全文文件都用统一标记分页，便于定位：

```
=== PDF_PAGE N ===
```

- 斋藤书：`N` 从 **0** 起（= PDF 内部页序，印刷页码通常 ≈ N+4）。
- 王树森书：`N` 从 **1** 起（= PDF 第 N 页，与 `目录_王树森.md` 页码一致）。

## 常用检索方法

```bash
# 在某本书里搜关键词并显示行号
grep -n "截断双Q" 参考资料/_index/全文_王树森.txt

# 跨两本书联合检索
grep -rn "贝尔曼方程" 参考资料/_index/*.txt

# 先看目录定位到第几页，再去全文里跳转
grep -n "PDF_PAGE 175" 参考资料/_index/全文_王树森.txt
```

## 重新生成索引

资料更新后，在项目根目录运行：

```bash
python 参考资料/_index/build_index.py            # 重建全部
python 参考资料/_index/build_index.py --only wang # 只重建王树森
python 参考资料/_index/build_index.py --only saito# 只重建斋藤
```

> 扫描版（王树森）的全文来自 OCR，**公式与图表可能识别有误**，涉及这两类内容时请对照原书 PDF。
> `目录_王树森.md` 由标题行自动抽取，页码可能有 ±1~2 页误差，个别章标题可能因 OCR 换行而略有截断。
