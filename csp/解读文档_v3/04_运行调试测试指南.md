## 1. 环境准备

### 1.1 依赖安装
新版没带 `requirements.txt`，可参考旧版 `EarnMore-main/requirements.txt`，核心依赖：

```bash
# 建议 Python 3.10/3.11，先建虚拟环境
conda create -n earnmore python=3.11 -y
conda activate earnmore

# PyTorch（按你的 CUDA 版本装，CPU 也能跑冒烟）
pip install torch

# 论文/代码核心依赖
pip install timm==0.9.2 mmengine==0.7.2 gym==0.26.0 \
            scikit-learn pandas numpy scipy \
            iopath prettytable kaleido seaborn tensorboard

# 环境/工具用到的
pip install quantstats          # 环境算夏普奖励用（qs_stats.sharpe）
pip install scikit-optimize     # hyperopt 贝叶斯搜索用（skopt）
pip install psutil              # scheduler 资源监控用
```

> 💡 版本踩坑：`gym==0.26.0` 的 `reset()/step()` 是"新接口"（返回 5 元组），代码已按新接口写；别误装 0.21。`mmengine` 提供 `Registry + Config` 那套机制。

### 1.2 关键：GPU vs CPU 会自动切换（务必知道）
配置文件顶部 `is_gpu_available = check_gpu_available()` 会**自动判断**，两套参数差异巨大：

| | GPU 分支（完整 EarnMore） | CPU 分支（轻量冒烟） |
|---|---|---|
| `num_stocks`(GSP) | 1000 | **5** |
| `batch_size` | 32 | 8 |
| `buffer_size` | 4096 | 512 |
| `embed_dim` | 128 | 64 |
| `if_use_rep`（MAE表征） | **True** | **False** |
| `if_use_beta`（掩码惩罚） | **True** | **False** |
| Agent | `AgentMaskSAC`（完整掩码版） | `AgentSAC`（普通SAC，无掩码） |

> ⚠️ **CPU 模式不是完整的 EarnMore**——它关掉了可掩码表征和掩码惩罚、退化成普通 SAC，只用来"快速跑通流程、验证环境没装错"。**想复现论文效果必须用 GPU 分支。** 学习算法以 GPU 分支为准。

### 1.3 数据准备
配置里数据路径写死指向 `datasets/csp_data_cut/`，需要三样东西（缺一不可）：

```
datasets/csp_data_cut/
├── features/                  # 每只股票一个 CSV，文件名=股票代码.csv
│   ├── 600000.SH.csv          #   列含: trade_date + 各技术指标 + 时序列 + 标签
│   └── ...
├── stocks_cut.txt             # 全局股票池 GSP：一行一个股票代码
└── aux_stocks_files_cleaned/  # 各 CSP 子池定义：每个 txt 一个子池(如 01_IT.txt)
    ├── 01_IT.txt
    └── ...
```

- CSV 需含配置里 `features` / `temporals_name`(weekday/day/month) / `labels` 指定的列，且有 `trade_date` 列（环境用它做日期索引、切训练/验证期）。
- 若你只有 `datasets/csp_data`（完整）没有 `csp_data_cut`（裁剪版），可改 config 的 `data_path` 指向 `csp_data`，或用 `tools/preprocess.py` 预处理生成。
- `generate_test_data.py`（项目根）可生成少量假数据用于"先把流程跑通"。

## 2. 路径 A：跑通一次单训练（推荐起步）

### 2.1 最小命令
```bash
cd EarnMore-main_v20260610
python tools/train.py --config configs/mask_sac_portfolio_management.py --root .
```
- `--config`：用哪个算法配置（mask_sac 即 EarnMore 主角）。
- `--root .`：项目根目录（其余相对路径都基于它拼接；新版会把相对路径转绝对）。
- `--monitor`（可选）：启用训练监控（早停、指标记录到 CSV）。
- `--workdir` / `--tag`（可选）：自定义工作目录/实验标签。

### 2.2 跑起来会发生什么（对照 `train.py`）
1. 读配置 → 造 `Dataset`（打印 init stocks / dataframe / aux stocks）。
2. 造**训练环境** `EnvironmentASR`（打印 features/prices shape、dates range、"stock markets inferred"）。
3. 造**验证环境**：每个 CSP 子池一个（含 id=0 的完整 GSP）。
4. 造 `AgentMaskSAC`（GPU）或 `AgentSAC`（CPU）。
5. 预填充 ReplayBuffer → 进入 `for episode` 主循环：
   - `train_one_episode`：反复"采样→`update_net` 五件套更新"，打印 Critic/Actor/Alpha/Beta/Rep 各损失表。
   - `validate`：在各子池上算 ASR/ARR/SR/MDD 等，打印验证表。
   - 验证集 `env0`(完整GSP) 指标创新高 → 存 `best.pth`。
6. 全程写 TensorBoard 到工作目录、写 `train_log.txt` / `train_infos.txt`。

### 2.3 产出文件在哪
工作目录 = `root/workdir`（默认 `workdir`，配置里可改）：
```
workdir/
├── events.out.tfevents.*      # TensorBoard 曲线
├── best.pth                   # 验证最优模型(断点续训也用它)
├── train_log.txt              # 每 episode 的指标(json 一行一条)
├── train_infos.txt            # 每 episode 的详细信息
└── logs/*.csv                 # 训练/价值函数/组合日数据(监控器写)
```
看曲线：`tensorboard --logdir workdir`。

### 2.4 测试/回测
```bash
python tools/test.py --config configs/mask_sac_portfolio_management.py --root .
```
`tools/test.py` 加载训练好的模型、在测试期(`test_start_date~test_end_date`)上回测，输出 6 个金融指标（ARR/SR/CR/SoR/MDD/VOL）。

## 3. 调试技巧

### 3.1 先用"小配置"快速跑通
新版主配置 `num_episodes = 5` 本就是**冒烟配置**（不是正式训练）。再配合 CPU 分支（`num_stocks=5`），几分钟就能跑完一轮，专门用来验证"环境/数据/流程"没问题。正式训练把 `num_episodes` 调回 200+ 并上 GPU。

### 3.2 在 PyCharm/VSCode 里断点调试
入口是 `tools/train.py: main()`。建议断点位置：
- `dataset = DATASET.build(cfg.dataset)` 后 → 看 `dataset.stocks`、`dataset.aux_stocks[0]["mask"]` 是否符合预期。
- `train_environment = ENVIRONMENT.build(...)` 后 → 看 `features.shape == [N, T, F]`、`dates` 范围对不对。
- `agent.update_net(buffer)` 内（`mask_sac.py`）→ 看 `q_labels`、各 loss（这是论文公式 5/6/7/8 的落地）。
- 环境 `step()`（`pm_based_portfolio_ASR.py`）→ 看 `is_rebalance_day`、`_step_rebalance` 里目标股数经各约束后的变化。

> 调试命令行参数：在 IDE 的运行配置里把 `--config configs/mask_sac_portfolio_management.py --root .` 填进 Parameters。

### 3.3 常见报错与排查
| 现象 | 多半原因 | 解决 |
|---|---|---|
| `FileNotFoundError: .../stocks_cut.txt` 或 `xxx.csv` | 数据路径不对/数据没准备 | 改 config 的 `data_path/stocks_path/aux_stocks_path`，或先 `generate_test_data.py` 造假数据 |
| `KeyError: 'trade_date'` / 缺某特征列 | CSV 列名与 config 的 features/temporals 不匹配 | 核对 CSV 列名 ↔ config 列表；用 `tools/preprocess.py` 规范化 |
| 训练极慢 / 显存 OOM | 误用 GPU 分支的大参数 / `num_stocks` 太大 | 先用 CPU 冒烟配置；或调小 `batch_size/buffer_size/num_stocks` |
| `ModuleNotFoundError: quantstats / skopt / psutil` | 缺依赖 | 见 1.1 补装 |
| 结果是普通 SAC、没有掩码效果 | 当前在 CPU 分支（`if_use_rep/beta=False`） | 上 GPU，或手动把这两个开关改 True（CPU 会很慢） |
| `gym.error` 关于 reset/step 返回值 | gym 版本不对 | 装 `gym==0.26.0` |
| 验证指标键名报错（assert False） | 验证环境没产出 `ASR_env0/ARR%_env0` | 多半是某子池数据为空/日期段无数据，检查 val 期数据 |

### 3.4 关掉 A 股交易摩擦做"纯算法"调试
新版环境默认开了 t+N 调仓/T+1/涨跌停/整手/费用/滑点（走 `__init__` 默认值）。想排除这些干扰、贴近论文做纯算法验证，在 config 的 `environment` dict 里显式加：
```python
environment = dict(
    type = "EnvironmentASR",
    # ... 原有项 ...
    rebalance_period = 1,        # 每天可调仓(接近论文)
    enable_t1_rule = False,
    enable_price_limit = False,
    enable_lot_size = False,
    enable_slippage = False,
)
```
或干脆把 `type` 换成 `pm_based_portfolio_value`（贴近论文的简单环境，奖励=市值变化）。

## 4. 路径 B：大规模实验流水线（速览）

完整细节见 `05_experiments工程化工具详解.md`，这里给一条最短跑通链（来自 `quickhelp.txt`）：

```bash
cd experiments

# ① 超参搜索：生成一批带不同超参/日期切分的实验(每个=一个 exp_xxx 目录+config.py)
python hyperopt.py random-search --template mask_sac_base --num-samples 2 \
       --train-start-date 2021-10-01 --train-window-months 10 \
       --val-start-date 2022-10-01 --val-window-months 6 --slide-step-months 2

# ② 调度器：并发跑这些实验(每个实验起一个 train.py 子进程，自动重试/早停)
python scheduler.py --traincmd "<绝对路径>/tools/train.py" run --max-concurrent 1 --max-retries 3

# ③ 监控：实时看某实验状态 / 综合分析
python monitor.py status --experiment exp_001_xxx
python monitor.py comprehensive-analysis --experiment exp_001_xxx

# ④ 可视化：批量出图 / 跨实验对比
python visualizer.py plot-all-experiments --experiments-dir experiments
python visualizer.py compare-experiments --experiments-dir experiments

# ⑤ 选最优：扫描所有实验、评估稳定性、按指标排名、给出最优稳定模型
python best_model_finder.py --min-stability 30 report
```

> ⚠️ 这些命令里的路径（`--traincmd`、`g_strRoot`）需改成你机器的实际绝对路径（见 `quickhelp.txt` 顶部）。`best_model_finder.py` 运行前还需设 `g_episodeCount/g_patience/g_metrics` 等前提参数。

## 5. 一页速查（Cheat Sheet）

```text
# 单次训练 / 测试
python tools/train.py --config configs/mask_sac_portfolio_management.py --root .
python tools/train.py --config configs/mask_sac_portfolio_management.py --root . --monitor
python tools/test.py  --config configs/mask_sac_portfolio_management.py --root .

# 实验流水线(在 experiments/ 下)
python experiment_manager.py list-experiments          # 看所有实验
python hyperopt.py random-search --template mask_sac_base --num-samples 2 ...
python scheduler.py --traincmd "<abs>/tools/train.py" run --max-concurrent 1
python monitor.py status --experiment <exp_name>
python visualizer.py compare-experiments --experiments-dir experiments
python best_model_finder.py --min-stability 30 report

# 关键开关(configs/mask_sac_portfolio_management.py)
num_episodes      # 训练轮数(5=冒烟, 200+=正式)
num_stocks        # GSP 股票数(GPU 1000 / CPU 5)
if_use_rep        # 是否用 MAE 可掩码表征(GPU True / CPU False)
if_use_beta       # 是否用掩码监督惩罚(GPU True / CPU False)
T                 # 重加权温度(0.01, 越小越稀疏)
environment.type  # EnvironmentASR(A股真实) / pm_based_portfolio_value(贴近论文)
```
