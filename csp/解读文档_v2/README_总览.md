## 二、互校与勘误记录（根据论文原文核对）

1. **SARL / DeepTrader 张冠李戴（已确认两版翻译均正确）**
   论文相关工作里这句在 PDF 双栏排版下字符交错，解码后为：*"SARL [35] 把价格涨跌预测作为附加状态；**DeepTrader [32]** 用市场指标平衡风险收益、并用独特图结构生成组合"*。
   - 两套源翻译（详注版 01、精简版翻译）此处都**正确**。
   - 注：同目录另有一份 `csp/EarnMore_论文中英对照.md` 早期版曾把图结构误归给 SARL，已单独修正；v2 此处与论文一致。

2. **折扣因子 $\gamma$ 的出处**：论文正文只写 $\gamma\in[0,1)$、**未给具体值**；$\gamma=0.99$ 来自**代码**（SAC 惯例），v2 已注明"论文给范围、代码取 0.99"。

3. **特征维度 $F$**：论文 SP500 设定为 **$F=102$**（含 OHLC+技术指标+时序，已剔除成交量）；本仓库魔改版代码改成 **67**。v2 在举例处同时标注两者，避免混淆。

4. **测试起始日 2018-01-16 vs 2018-01-25**：论文正文写"2018-01-16 起"，而表 1 的首个测试段起于"2018-01-26"——这是**论文自身的不一致**（疑似笔误）。v2 表 1 以表格值为准，并加注说明。

5. **奖励函数差异（已实地验证代码）**：论文原版奖励 $r_t=V_t-V_{t-1}$（见 `pm_based_portfolio_value.py`，代码确为 `new_portfolio_value - old_portfolio_value`）；当前 `EnvironmentASR` 改用**年化夏普比率**并裁剪为非负（代码确为 `qs_stats.sharpe(rets, rf=0.02)` 后 `max(reward, 0)`）。两套源文档此论断均**属实**。

## 四、一句话抓住全文

> **EarnMore = SAC（强化学习算法）+ MAE（掩码自编码器表征学习）+ 投资组合管理（应用任务）**。
> 核心创新：把 MAE 的"掩码"思想搬到 RL 的状态表征上——用可学习掩码标记 `[M]` 统一表示"投资者不想要的股票"，经自监督掩码-重建学到既能补缺、又保留股票间关系的表征；只在最大的全局股票池（GSP）上**训练一次**，推理时面对任意子池（CSP）只需改变掩码即可，**无需重训**。这正是它相对"从零训练 / 微调 / 动作掩码"三种朴素做法的根本优势。
