## 🎯 三条主线一句话总结

**EarnMore = SAC(强化学习算法) + MAE(掩码自编码器表征学习) + 投资组合管理(应用任务)**

- **强化学习主线**：MDP → 价值函数 → 贝尔曼方程 → TD/Q学习 → 策略梯度 → Actor-Critic → **SAC**（论文用的算法）
- **表征学习主线**：自编码器 → 自监督学习 → **MAE 掩码自编码器**（论文第一大创新："可掩码股票表征"）
- **应用主线**：OHLCV/技术指标 → 投资组合 → 收益与风险指标(ARR/SR/MDD…)

## 💡 论文核心创新(用一句话记住)

> **把 MAE 的"掩码"思想搬到 RL 的状态表征上**：用可学习的掩码标记 `[M]` 统一表示"投资者不想要的股票"，通过自监督掩码-重构学到既能填补缺失、又保留股票间关系的表征；只需在最大的全局股票池(GSP)上**训练一次**，推理时面对投资者任意指定的子池(CSP)只要改变掩码即可，**无需重训**——这就是它相比"从零训练/微调/动作掩码"三种朴素做法的根本优势。
