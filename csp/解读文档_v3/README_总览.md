## 三、新版环境的七大新增机制（A 股真实交易）

| 机制 | 默认参数 | 作用 |
|---|---|---|
| t+N 调仓 | `rebalance_period=5` | 每 5 个交易日才真正换仓，其余只持有 |
| T+1 规则 | `enable_t1_rule=True` | 当天买入当天不可卖（冻结，次日解冻） |
| 涨跌停限制 | `enable_price_limit=True` | 按代码推断幅度(ST5%/科创创业20%/北交所30%/主板10%)，封板禁买/禁卖 |
| 整手约束 | `lot_size=100` | 买卖股数取整到 100 股整数倍 |
| 完整交易成本 | — | 佣金(万0.855,最低5元) + 印花税(万5,仅卖) + 过户费(万0.2,仅沪) |
| 滑点 | `slip_perc=0.001` | 买贵卖贱 0.1%，并限制在当日[低,高]价内 |
| 现金留存 | `cash_reserve_ratio=0.01` | 永远留 1% 现金缓冲 |

> ⚠️ 这些规则当前走 `__init__` 默认值——新版 config 的 `environment` 段并未显式传入它们。想改，需在 config 的 environment dict 里加，或改默认值。详见 `03` 第 4.2、7 节。

## 四、与论文的关系（重要提醒）

- **状态/动作的 MDP 定义不变**：状态仍是 `[股票, 天, 特征]` 窗口，动作仍是 `[现金, 各股票权重]`。
- **奖励改了**：论文原版 = 市值变化 $V_t-V_{t-1}$；本仓库（新旧版都）= 年化夏普比率（裁剪非负）。
- **环境摩擦是论文外的工程落地**：论文用美股、无 A 股交易细节；新版把 A 股交易规则加进来，更贴近实盘，但训练更慢、回测收益更"真实"（更低）。
- 想复现论文/做纯算法学习：可把 `environment.type` 换成 `pm_based_portfolio_value`（贴近论文的简单环境），或显式关掉新机制。

## 五、一句话抓住全文

> **EarnMore = SAC（强化学习算法）+ MAE（掩码自编码器表征学习）+ 投资组合管理（应用任务）**。
> 核心创新：把 MAE 的"掩码"思想搬到 RL 的状态表征上——用可学习掩码标记 `[M]` 统一表示"投资者不想要的股票"，经自监督掩码-重建学到既能补缺、又保留股票间关系的表征；只在最大全局股票池上**训练一次**，推理时面对任意子池只需改掩码即可，**无需重训**。
> 新版在此基础上，把"在哪儿交易"从理想环境换成了**A 股真实交易模拟器**——算法没变，但落地更接近实盘。
