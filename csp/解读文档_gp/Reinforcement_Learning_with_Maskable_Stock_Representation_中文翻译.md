## 摘要

投资组合管理是金融交易中的基础任务，它研究如何周期性地把资金重新分配到不同股票中，以追求长期收益。近年来，强化学习通过与金融市场交互，展示了训练盈利智能体的潜力。

但是，已有工作大多关注固定股票池，这和投资者的真实需求并不一致。不同投资者对市场状态的理解不同，目标股票池差异很大；同一个投资者也可能临时调整想交易的股票，例如加入一只热门股票。因此，真实场景里会出现**可定制股票池**（Customizable Stock Pools, CSPs）。

现有强化学习方法即使只面对股票池的微小变化，也通常需要重新训练智能体，这会带来很高的计算成本和不稳定的表现。为了解决这个问题，论文提出 **EarnMore**：一个带有可掩码股票表示（Maskable Stock Representation）的强化学习框架。它只需要在全局股票池（Global Stock Pool, GSP）上一次训练，就能处理不同 CSP 的投资组合管理。

EarnMore 的核心包括三点：

1. 引入一种机制，把目标股票池外的股票表示掩码掉。
2. 通过自监督的“遮蔽-重建”过程学习有意义的股票表示。
3. 设计重加权机制，使投资组合更集中于有利股票，并忽略目标池外股票。

论文在美国股票市场的 8 个子股票池上进行了大量实验。结果显示，EarnMore 在 6 个常用金融指标上显著优于 14 个先进基线方法，收益指标提升超过 40%。

关键词：Portfolio Management、Reinforcement Learning、Representation Learning。

## 1 引言

股票市场总市值超过 90 万亿美元，吸引了全世界大量投资者。投资组合管理通过动态分配不同股票的资金比例，帮助投资者获取收益。强化学习擅长解决复杂的序列决策问题，例如围棋和矩阵乘法，因此也逐渐成为金融交易任务中的重要方法，包括算法交易、投资组合管理、订单执行和做市。

在已有投资组合管理研究中，强化学习智能体通常基于一个固定股票池做投资决策。当投资者想改变目标股票池时，模型往往需要重新训练，成本很高。并且，投资者难以参与或影响智能体的决策过程，模型对用户来说不够可控。

作者认为，投资者和智能体可以更好地协作。投资者可能不了解所有股票走势、股票之间隐藏关系和整体市场动态；智能体也可能偶尔犯错，并且不像人类一样能从新闻、经验、行业变化等多渠道获得信息。例如，某只股票被退市时，智能体如果仍把它当作候选投资对象，就可能造成损失。又如，某只股票未来潜力很大，投资者可能希望把它加入目标池以提高收益。因此，论文提出了**可定制股票池下的投资组合管理**任务。

在真实交易中，CSP 的需求非常普遍。证券公司需要为具有不同偏好的大量投资者提供实时组合建议；投资者也会根据市场情况不定期调整股票池。直接处理 CSP 有三种朴素方法：

1. 为每个 CSP 从头训练一个智能体。问题是组合数量爆炸，例如从 30 只股票中选 5 只就超过 14 万种组合。
2. 调整策略网络输出维度，把 GSP 的动作空间映射到 CSP 后微调。连续动作空间下的微调可能和重新训练一样耗时。
3. 动作掩码：对不想投资的股票 logits 减去很大常数，使其权重变小。但这种方式只是人为改动输出，并没有让智能体真正理解 CSP 中哪些股票被投资者排除。

论文指出，已有动态资产数量方法仍存在限制，例如为每只股票训练 actor 和 critic 会消耗大量资源，也难以在投资过程中同时改变股票数量和组成。

为了处理 CSP，论文面对两个主要挑战：

1. 如何为不同大小、不同组成的股票池学习统一且对齐的表示；
2. 如何引导强化学习智能体把资金集中到有利股票上，并忽略目标池外股票。

EarnMore 通过一次训练解决这些问题。它允许投资过程中动态调整股票池，从而生成更贴合投资者偏好的投资组合。论文贡献包括：

1. 提出可学习的 masked token，用来表示投资者不看好的股票，使不同大小和组成的股票池可以统一表示。
2. 使用自监督遮蔽和重建过程学习股票嵌入，捕捉股票关系。
3. 提出重加权机制，重新缩放组合权重分布，使组合集中于有利股票并忽略目标池外股票。
4. 在美国市场 8 个子股票池实验中，EarnMore 通过一次训练优于 14 个基线方法。

## 2 相关工作

### 2.1 投资组合管理

投资组合管理的目标是合理配置资源，在获取最优收益的同时规避风险。传统规则方法包括均值回归和动量策略。均值回归倾向于买入低价股票、卖出高价股票；动量策略则认为近期表现强的资产趋势会继续。横截面动量和时间序列动量是两类经典方法。

但是，传统规则方法难以捕捉变化市场中的短暂模式，通常只在特定场景表现较好。

近年来，预测式方法在某些任务中超过规则方法。这类方法把投资组合管理当作监督学习任务，预测未来收益或价格涨跌，再用启发式策略生成器分配资产。方法包括 XGBoost、LightGBM、ALSTM、TCN 等。但金融市场波动大、噪声强，准确预测未来价格非常困难；预测信号和真实盈利交易动作之间也存在难以弥合的差距。

强化学习与投资组合管理的结合近年取得进展。EIIE 使用 CNN 做特征提取，用强化学习做决策；Investor-Imitator 模仿投资者行为；SARL 把价格涨跌预测作为附加状态；DeepTrader 用图结构建模股票关系并平衡风险收益；HRPM 使用层次化框架考虑长期收益和滑点成本；DeepScalper 结合日内交易和风险感知任务。

### 2.2 掩码自编码器

Masked Autoencoders（MAE）是一类用于自监督学习的神经网络，可以学习有效嵌入。自编码器最初常用于图像、视频、音频等领域，近年来也被广泛用于时间序列预测。PatchTST 把时间序列切分成 patch，并通过自监督学习提升多变量时间序列预测能力。SimMTM、Ti-MAE 等工作也用 MAE 学习时间序列表示。

金融市场的信噪比通常低于一般时间序列。论文认为，在金融场景中使用 MAE 进行自监督学习，可以降低数据维度、过滤噪声、突出关键信息。MAE 还能发现股票之间隐藏关系，并用 masked token 表示投资者不看好的股票，从而改善投资者和智能体的协作。

## 3 预备知识

### 3.1 定义与公式

**定义 1：OHLCV。**  
OHLCV 指 Open、High、Low、Close、Volume，即开盘价、最高价、最低价、收盘价和成交量。股票 i 在时间 t 的 OHLCV 记为一个向量。

**定义 2：技术指标。**  
技术指标是基于历史 OHLCV 按公式计算得到的特征。论文把时间 t 的技术指标向量记为 `Y_t`。每个指标都由过去若干时间步的数据和相应超参数计算得到。

**定义 3：投资组合。**  
投资组合是金融资产的组合，记为 `W_t = [w_t^0, w_t^1, ..., w_t^N]`。其中第 0 个资产是无风险现金，其余 N 个资产是股票。每个资产 i 的权重 `w_t^i` 表示资金占比，满仓约束为所有权重之和等于 1。

**定义 4：组合价值。**  
时间 t 的组合价值 `V_t` 是组合中所有资产价值之和。`V_0` 是初始现金。组合价值根据现金权重、股票权重和股票收盘价变化计算。直观理解是：现金部分不随股价涨跌变化，股票部分根据各股票收益率加权变化。

### 3.2 问题形式化

论文把投资组合管理建模为马尔可夫决策过程（MDP）。在标准强化学习场景中，智能体（投资者）在离散时间与环境（金融市场）交互，采取动作（投资决策），获得奖励（利润）。目标是在长期投资区间内最大化最终组合价值。

MDP 由五元组组成：状态集合 `S`、动作集合 `A`、状态转移函数、奖励函数和折扣因子 `gamma`。策略 `pi(a|s)` 表示在状态 s 下选择动作 a 的概率。

在 CSP 场景中，论文把全局股票池记为 `U`，其中包含 N 只股票。通过随机 mask 投资者不喜欢的股票，可以生成很多 CSP。传统固定股票池方法可以看成本文方法的特例，也就是 CSP 等于 GSP。

**状态。**  
GSP 的股票时间序列由三部分组成：历史 OHLC 价格、技术指标、时间信息。若投资者 mask 掉部分股票，则先得到 CSP 特征，再用可学习的 masked token 把维度补回 GSP 维度。这样，状态仍保持固定长度，同时被 mask 的位置也被明确标出。

**动作。**  
动作就是投资组合向量，包括现金权重、目标池内股票权重、被 mask 股票的权重。理想情况下，被投资者排除的股票权重应接近 0。

**奖励。**  
论文沿用已有研究，把每个交易时间步的奖励定义为组合价值变化：`r_t = V_t - V_{t-1}`。

## 4 EarnMore

EarnMore 是一个在 GSP 上一次训练、可以投资多个 CSP 的强化学习框架。投资者可以根据个人偏好选择股票池，也可以在交易过程中动态调整股票池。

EarnMore 包含三个主要部分：

1. **可掩码股票表示**：统一表示不同大小和组成的 CSP；
2. **CSP 下的强化学习优化**：基于 SAC 训练投资组合策略；
3. **重加权机制**：让组合更集中于有利股票，忽略不利股票。

### 4.1 CSP 的可掩码股票表示

在做投资决策前，不同 CSP 需要一致的表示。如果只把 CSP 内股票输入智能体，并直接丢弃被 mask 股票，会产生三个问题：

1. 智能体动作维度无法适配不同 CSP 大小；
2. 当两个 CSP 股票数量相同但股票不同，智能体难以区分；
3. 丢弃不利股票会损失股票之间的关系信息。

为解决这些问题，论文引入可掩码股票表示。它识别每只股票在 GSP 中的位置，并使用两层表示：

1. **股票级表示**：Module (a)，描述每只股票自身的历史时间序列；
2. **池级表示**：Module (b)，通过 mask 和重建学习股票池内部关系。

**股票级表示。**  
论文利用价格、技术指标和时间特征生成每只股票的 embedding。参照 TimesNet，模型用 1D 卷积处理密集股票特征，用 embedding 层处理稀疏时间特征，最后把两者相加得到股票级表示。

**池级表示。**  
股票级表示主要描述单只股票的纵向时间序列信息，不能充分捕捉股票之间的横向关系。直接 mask 某些股票可能丢失重要关系。为此，论文通过遮蔽和重建过程学习池级表示，加强 GSP 中股票之间的联系。

训练时，EarnMore 使用自适应 mask 策略模拟不同股票数量和组成的 CSP。mask 比率从截断高斯分布中采样。这样可以统一高 mask 比例和低 mask 比例的股票池训练。

构造过程如下：

1. 对股票级 embedding 随机 mask 一部分股票；
2. 只把未 mask 的 embedding 输入 encoder；
3. 用可学习的 masked token 填回被 mask 的位置；
4. decoder 重建被 mask 股票的价格；
5. 填回 masked token 后的潜在 embedding 就是可掩码股票表示。

masked token 让智能体知道哪些股票是投资者不喜欢的，从而尊重投资者偏好。论文还保留 `[CLS]` token，用于理解现金如何分配；它可以捕捉全局序列信息。

### 4.2 CSP 下的强化学习优化

EarnMore 的强化学习过程基于 Soft Actor-Critic（SAC）。SAC 有两个主要组件：

1. **Actor**：根据包含 masked token 的潜在表示生成动作，也就是现金和股票权重；
2. **Critic**：根据状态表示和 Actor 动作评估组合表现，指导策略优化。

论文使用两种策略阻止模型给被 mask 股票分配权重：

1. 对 Actor 输出的组合权重加入额外监督损失；
2. 当被 mask 股票有非零投资权重时，在 TD error 中加入惩罚项。

实验发现第一种方式更好，因为监督损失能更直接地影响 Actor 的组合输出。

**Q 网络优化。**  
模型不用原始市场数据作为 Actor/Critic 输入，而是使用可掩码股票表示。Q 值网络通过最小化柔性贝尔曼残差学习。SAC 的目标中包含熵项，因此目标值大致是：即时奖励 + 折扣后的下一状态软价值。

**策略网络优化。**  
策略网络使用重参数化技巧，把动作表示为状态和高斯噪声的函数。策略目标是最小化 KL 散度形式的目标，也就是在提高 Q 值的同时保留熵，避免过早变得确定。

**Alpha 参数优化。**  
SAC 使用自动熵调节，让温度参数 alpha 根据目标熵自动变化。alpha 越大，策略越鼓励探索；alpha 越小，策略越倾向利用当前高价值动作。

**可掩码股票表示优化。**  
遮蔽和重建过程用均方误差优化，只对被 mask 股票的价格计算重建损失。论文认为单独预训练 encoder 有两个问题：自监督价格预测和 RL 决策之间存在任务差距；冻结 embedding 可能限制 RL 探索空间。因此，EarnMore 同时进行表示学习和 RL 优化，形成端到端模型。

训练每个 SAC batch 时，论文先优化 Q 网络，再优化 alpha、策略网络和可掩码股票表示。作者发现，如果把表示损失和其他三类损失简单加权求和一起优化，会影响 RL 采样数据分布，导致训练不稳定。

### 4.3 重加权方法

在连续投资组合动作空间中，智能体很难做精确决策。市场持续变化时，智能体可能过拟合固定市场模式，在高波动市场反应不足，从而给低收益甚至负收益股票分配很小但非零的资金。

在 CSP 场景中还会出现两个额外问题：

1. 状态表示包含 masked token，智能体仍可能给被 mask 股票分配资金；
2. 决策误差会让高收益股票的资金比例被低收益股票“抢走”。

论文用投资组合稀疏化解决这些问题。受 Boltzmann 分布和 Gumbel-Softmax 启发，作者在 softmax 中加入温度参数 `T`：

`Re(x)_i = exp(x_i / T) / sum_j exp(x_j / T)`

其中 x 是 Actor 的组合 logits。`T` 越小，分配越稀疏；当 `T` 接近 0 时，资金几乎都分给最高预期收益资产；`T=1` 时退化为普通 softmax；`T>1` 时会减小分配差异，甚至接近平均分配。训练和测试阶段都会使用重加权。

## 5 实验

论文通过一系列实验评估 EarnMore：

1. 在两个真实美国金融市场中证明 EarnMore 在 GSP 上优于基线；
2. 根据三种投资者偏好构造 6 个 CSP，验证模型能适应投资者偏好和交易过程中的个人决策；
3. 做消融实验回答三个问题：
   - RQ1：EarnMore 各组件是否有用？
   - RQ2：为什么直接方法不能很好处理 CSP？
   - RQ3：EarnMore 效率如何？

1. 不同市场条件和事件，例如 COVID-19、地缘政治冲突、牛市和熊市；

### 5.2 评估指标

论文使用 6 个金融指标比较 EarnMore 和基线方法，包括 1 个收益指标、3 个风险调整收益指标和 2 个风险指标。指标定义见附录 A。

### 5.3 基线方法

论文选取 14 个代表性基线方法，分为四类：

1. 规则方法：BLSW、CSM 等；
2. 机器学习方法：XGBoost、LightGBM；
3. 深度学习方法：ALSTM、TCN；
4. 强化学习方法：PG、SAC、PPO、EIIE、SARL、IMIT、DeepTrader。

### 5.4 实现细节

实验在 Nvidia A6000 GPU 上进行。超参数通过网格搜索确定。机器学习和深度学习基线基于 Qlib 实现，其余基线使用公开实现的默认设置。实验以 `3 个日期切分 × 3 个随机种子` 运行，并报告平均性能。

### 5.5 结果与分析

**GSP 上的表现。**  
在 SP500 上，EarnMore 的 ARR 达到 97.17%，SR 达到 2.032，显著高于第二名。DJ30 上，EarnMore 在 ARR、SR、CR、SoR 上分别取得 46.7%、8.9%、6.2%、2.4% 的提升。

表 2 中部分关键结果：

| 市场 | 方法 | ARR% | SR | CR | SoR | MDD% | VOL |
|---|---|---:|---:|---:|---:|---:|---:|
| SP500 | DeepTrader | 60.29 | 1.980 | 2.195 | 34.26 | 28.58 | 0.013 |
| SP500 | EarnMore | 97.17 | 2.032 | 2.506 | 42.16 | 28.12 | 0.023 |
| DJ30 | DeepTrader | 32.23 | 1.335 | 1.440 | 27.11 | 21.19 | 0.013 |
| DJ30 | EarnMore | 47.29 | 1.454 | 1.692 | 28.04 | 21.65 | 0.018 |

论文也指出，机器学习方法在风险控制上较强，但收益不突出。树模型对异常值和噪声更鲁棒，因此有助于降低决策风险。EarnMore 在风险指标上略逊于部分基线，但总体可比。作者强调 EarnMore 的优先目标是最大化最终组合价值，因此风险控制上做了一定折中。

COVID-19 疫情高峰期（2020-02-14 到 2020-03-20）导致 SP500 和 DJ30 分别下跌 31.81% 和 34.78%。图 3 显示 EarnMore 受影响程度小于多数基线，并在市场反弹后继续获得收益。即使市场下跌，EarnMore 也能识别反弹后更有收益潜力的股票。

**CSP 上的表现。**  
论文从两个方面展示 CSP 的有效性：一是比较基于投资者偏好构造的 CSP 的收益表现；二是展示交易过程中 EarnMore 对投资者个人决策的适应性和鲁棒性。

表 3 关键结果：

| 市场 | 股票池 | 方法 | ARR% | SR |
|---|---|---|---:|---:|
| SP500 | CSP1 | EarnMore | 122.61 | 2.278 |
| SP500 | CSP2 | EarnMore | 110.11 | 2.279 |
| SP500 | CSP3 | EarnMore | 93.67 | 2.120 |
| DJ30 | CSP1 | EarnMore | 53.99 | 1.810 |
| DJ30 | CSP2 | EarnMore | 43.40 | 1.549 |
| DJ30 | CSP3 | EarnMore | 43.46 | 1.572 |

EarnMore 在所有 CSP 上都表现突出。CSP1 主要包含科技股票，EarnMore 的盈利能力显著高于其他方法，这与长期科技股上涨相符合。金融和服务行业 CSP 上，EarnMore 也取得明显收益提升。整体来看，EarnMore 能自动适应投资者偏好，并生成较高收益。

论文还展示了动态调整 CSP 的真实场景：

1. GE 于 2018-06-26 被移出 SP500。移除 GE 后，EarnMore 能适应投资者决策并取得小幅收益提升。
2. 2022 年 3 月至 6 月，Apple 股价因战争影响、手机停机事件等因素大幅下跌近 25%。从 DJ30 中排除 AAPL 可明显提高收益。
3. 作者故意在 MSFT 下跌期间把它加入 SP500 的 CSP2，以测试模型鲁棒性。EarnMore 能筛掉该股票，降低 MSFT 权重，对整体收益影响很小。
4. Goldman Sachs 发布钢铁项目和新能源汽车进展，释放 2021 年股价上涨信号。将 GS 加入股票池后，EarnMore 获得更明显收益增长。

### 5.6 消融实验

论文研究三个组件的作用：可掩码股票表示、CSP、重加权方法。

比较 `EarnMore-w/o-M` 和完整 EarnMore 可发现，池级可掩码股票表示带来显著提升，并降低投资风险。GSP 和 CSP 都受益于该表示，且 CSP 表现更好，说明更聚焦的股票选择可能带来更高收益。

比较 `EarnMore-w/o-MR` 和 `EarnMore-w/o-M` 可发现，重加权通过稀疏化投资组合显著提升收益，但可能增加最大回撤风险。原因是降低组合多样性会减少跨行业分散机会，在行业较少的 CSP 中尤其可能提高风险；但集中投资少数行业也可能显著提高收益，抵消部分风险损失。

**为什么直接方法效果不好？**  
从 GSP 转到 CSP 的三种简单方法是从头训练、微调、动作掩码。前两者不能在交易中实时调整股票池；动作掩码依赖 logits 人为修正，不能准确表达智能体真实决策。图 5(a) 显示 EarnMore 在 DJ30 的 ARR 和 SR 上显著优于这些直接方法。

**效率。**  
EarnMore 只训练一次，就能服务多个投资者的 CSP 需求。随着 CSP 数量增加，其他方法需要重复训练或微调，成本快速上升，而 EarnMore 的效率优势更加明显。

## 6 结论与未来方向

论文提出了一种新的强化学习投资组合管理框架 EarnMore，使模型具有投资者偏好和个人决策感知能力，能够处理可定制股票池。通过遮蔽和重建过程，模型增强了可掩码股票表示；通过重加权方法，模型提升了稀疏投资组合的收益表现。多项金融指标证明 EarnMore 优于基准方法。

未来方向包括：

1. 通过风险惩罚优化增强风险控制；
2. 构建更灵活、开放的可定制股票池，使股票添加和删除更方便。

## 附录 A：评估指标细节

论文比较 6 个金融指标：

1. **Annual Rate of Return, ARR**：年化平均收益率。根据最终组合价值、初始组合价值、总交易天数和一年交易日数计算。
2. **Sharpe Ratio, SR**：夏普比率，衡量单位波动风险下的收益，约等于收益率均值除以收益率标准差。
3. **Volatility, VOL**：波动率，即收益率的标准差。
4. **Maximum Drawdown, MDD**：最大回撤，衡量从任意历史峰值到低点的最大损失。
5. **Calmar Ratio, CR**：年化收益与最大回撤的比值，用于评估风险调整表现。
6. **Sortino Ratio, SoR**：索提诺比率，只关注下行风险，使用负收益标准差衡量风险。

## 附录 B：基线方法细节

规则方法：

- **BLSW**：基于均值回归，买入表现差的股票、卖出表现好的股票。
- **CSM**：动量策略，偏好近期表现强的资产。

机器学习方法：

- **XGBoost**：基于梯度提升决策树的监督学习模型。
- **LightGBM**：高效 GBDT，使用梯度单边采样和互斥特征捆绑。

深度学习方法：

- **ALSTM**：带外部注意力层的循环神经网络。
- **TCN**：用于时间序列建模的卷积神经网络结构。

强化学习方法：

- **PG**：直接优化策略函数，不显式估计价值函数。
- **SAC**：离策略 Actor-Critic 算法，使用熵正则和 soft value function。
- **PPO**：迭代更新策略，平衡探索与利用，并提升训练稳定性。
- **EIIE**：较早把 PM 建模为 MDP 的工作，用 CNN 提特征、RL 做组合决策。
- **SARL**：状态增强 RL，把价格涨跌预测作为附加状态。
- **Investor-Imitator**：通过模仿投资者行为进行投资组合管理。
- **DeepTrader**：用 RL 建模股票关系，并平衡风险收益。

## 附录 C：实现细节

状态维度为 `(B, N, D, F)`：

- `B = 128` 表示 batch size；
- `N` 是股票数量，DJ30 为 28，SP500 为 420；
- `D = 10` 表示历史天数；
- `F = 102` 表示特征总数，包括 OHLC、技术指标和时间信息。

由于 Volume 数值幅度很大，不利于 RL 训练，论文从特征中移除了成交量。Encoder、Decoder、Actor、Critic 都由 2 层带 GELU 激活的 MLP 组成，embedding 维度为 64。

超参数方面，horizon length 从 `{32, 64, 128, 256}` 中搜索，最佳为 128。batch size 为 128，buffer size 为 `1e5`，训练 2000 个 episode，优化器为 AdamW。SAC 的 RL 部分和 MAE 表示部分都使用 MSE Loss。Actor、Critic 和 MAE 的学习率从若干候选值中搜索，最佳为 `1e-5`。调度器使用带 warm-up 的 multi-step 学习率调度。重加权相关参数包括 mask ratio 下界 0.6、上界 0.8、均值 0.7、标准差 0.1；温度参数从 `{10, 5, 1, 0.5, 0.1, 0.05, 0.01}` 中选择，最佳为 0.1。

## 附录 D：训练与推理伪代码

**训练阶段：**

1. 输入 GSP 和市场数据；
2. 初始化 Q 网络、目标 Q 网络、策略网络、表示网络和 replay buffer；
3. 对每个环境步：
   - 由价格、技术指标、时间信息生成股票级 embedding；
   - 采样 mask ratio；
   - 对股票 embedding 执行 mask；
   - encoder 得到池级 embedding；
   - 用 masked token 填回原位置，得到可掩码股票表示；
   - 策略网络采样动作，并经重加权得到组合权重；
   - 与环境交互并存入 replay buffer；
4. 对每个梯度步：
   - 更新 Q 网络；
   - 更新策略网络；
   - 调整 alpha；
   - 软更新目标网络；
   - 更新表示网络。

**推理阶段：**

1. 输入 GSP 和投资者给定的一系列 CSP；
2. 对每个时间步：
   - 生成状态；
   - 生成股票级 embedding；
   - 根据当前 CSP 初始化 mask index；
   - 通过 encoder 和 masked token 得到可掩码股票表示；
   - 策略网络预测动作；
   - 输出当前 CSP 的投资组合。

## 附录 E：与基线方法的详细比较

论文在 SP500 和 DJ30 数据集上使用 ARR、SR、CR、SoR、MDD、VOL 六个指标比较 EarnMore 和 14 个基线方法。每个结果来自 3 个日期切分与 3 个随机种子的平均。

总体结论是：EarnMore 在所有数据集上显著提升收益潜力，同时只牺牲很小的风险控制能力。累计收益曲线显示，EarnMore 在多种市场阶段都具有最强盈利潜力。

2018 年 10 月，美国货币政策和经济对抗影响了投资者信心，导致美国股市下行。EarnMore 也受到影响，但恢复较快，整体仍优于其他方法。2020 年 COVID-19 高峰期，SP500 和 DJ30 大幅下跌，EarnMore 相比其他方法收益受影响更小，并在市场恢复后继续获利。2021 年美国股市开始恢复，EarnMore 更擅长识别具有上涨动量的股票。2022 年 3 月，地缘政治冲突造成短期下跌，EarnMore 在 SP500 上收益有明显波动，但在 DJ30 上仍保持较强上升趋势。
